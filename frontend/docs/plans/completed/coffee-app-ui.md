# UI кофейного приложения (drinkit copy)

Pixel-perfect тёмный интерфейс мобильного приложения для заказа кофе на React + Vite + TypeScript.
Стилизация — CSS Modules + CSS-переменные для дизайн-токенов. Данные статичные (моки). Все 5 экранов с навигацией между ними.
Целевой viewport: 360px–430px, обязательны safe areas сверху и снизу.

## Validation Commands
- `npm run lint`
- `npx tsc --noEmit`
- `npm run build`
- `npm run dev` (ручная проверка экранов в браузере при 360–430px)
